# KOVA — сайт сети серверов

Статичный сайт (GitHub Pages). Все визуалы — код (canvas-воксели), без бэкенда.

- `/` — главная (TFG / RPG)
- `/login/`, `/register/` — вход и регистрация (Discord или email; мок-сессия в localStorage)
- `/cabinet/` — личный кабинет
- `/launcher/` — дизайн лаунчера (все экраны)
- `/v1/`, `/kova/` — редиректы на главную
