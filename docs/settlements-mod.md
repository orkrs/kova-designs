# Мод «Поселения» (рабочее название)

> Дизайн механик — автор: dmitro yannin (владелец проекта KOVA). Документ фиксирует его решения; сайт показывает демо-версию интерфейса.

## Объём версии v1

- **Обзор** поселения: герб, название, уровень, ключевые цифры.
- **Управление**: название, герб, режим входа (свободный / по приглашению).
- **Роли**: мэр, казначей, дипломат; назначает мэр.
- **Жители**: список, приглашения, выход из поселения.
- **Голосования**: решения города принимают жители голосованием.
- **Склад и казна**: общие ресурсы поселения (не валюта).
- **Союзы**: объединения нескольких поселений.

## Позже: войны

- Сторона войны — **союз** или **отдельное поселение** (например, «Северный союз vs Чёрный Брод»).
- Война состоит из **нескольких битв**.
- Перед каждой битвой мод **случайно выбирает место битвы** и автоматически создаёт **голосование**: можно ли сторонам сражаться в этом месте.
- Если голосов «за» недостаточно — место **перевыбирается случайно**, и голосование создаётся заново.
- **Счёт войны** = количество выигранных битв каждой стороной (например, «3 : 1»).
